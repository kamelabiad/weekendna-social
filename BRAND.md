# Weekendna brand kit (for Claude, ChatGPT and anyone making content)

Logo files are in `brand/`. Use them as they are; never redraw, recolour, stretch or add effects.

## Where the logo lives (GitHub)
The logo files are committed in this repo, folder `brand/` on the `main` branch of `kamelabiad/weekendna-social`:
- https://github.com/kamelabiad/weekendna-social/tree/main/brand
- Direct files: https://github.com/kamelabiad/weekendna-social/blob/main/brand/weekendna-logo-dark.png (same folder for the others listed below).
They are the only approved logo files. Do not recreate the logo from text; use these PNGs (Kamel can also attach them directly in chat).

| File | Use on |
|---|---|
| `brand/weekendna-logo-dark.png` | light or white backgrounds (ink "weekend" + red "نا") |
| `brand/weekendna-logo-white.png` | photos and red backgrounds (all white) |
| `brand/weekendna-logo-white-red-accent.png` | dark photos (white "weekend" + red "نا") |
| `brand/weekendna-logo-on-red.png` | red brand cards |
| `brand/weekendna-icon-red.png` | round profile picture |

The wordmark is "weekend" in Outfit Bold plus the Arabic "نا" in IBM Plex Sans Arabic Bold. The "نا" is part of the logo only: all other text is English.

## Colours
- Red `#e0263b` (primary), ink `#222222`, soft pink `#fdedef`, dark `#1a181c`, white.

## Type
- Plus Jakarta Sans (headlines 800, body 500). Outfit only for the logo.

## Formats
- Carousels 1080x1350 (4:5). Reels and stories 1080x1920 (9:16).
- Logo top-left, small, about 40 px tall on a 1080 px canvas. Red pill for the "Found on Weekendna" kicker. Few words per slide; real listing photos only.

## Content rules (short)
English only. No day-use content. No owner first names. Prices only as shown on weekendna.com. Nothing is published without Kamel's approval. Full rules: `PLAYBOOK.md`; strategy: `MARKETING_DIRECTION.md`.
